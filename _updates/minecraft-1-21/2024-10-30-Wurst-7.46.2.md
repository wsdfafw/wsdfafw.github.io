## 变更日志

- 默认情况下，MobSpawnESP 将不再过滤掉任何生物都无法生成的太小的暗点，因为发现此过滤器有时会导致游戏崩溃。([/d/841](https://wurstforum.net/d/841))

- 在 MobSpawnESP 中添加了“Hitbox 检查”设置，允许您重新启用对太小的暗点的过滤器。“不稳定”选项与 MobSpawnESP 的旧行为相匹配，而“慢速”是过滤器的新版本，不会导致任何崩溃，但与“不稳定”相比，游戏速度会明显减慢。

- 修复了导航器主屏幕打开时天空中出现一些奇怪颜色的问题。

- 添加了类似于 Fabric API 所做的客户端测试的自动化端到端测试。每次代码更改时，GitHub Actions 都会[实际运行 Wurst](https://x.com/Wurst_Imperium/status/1849098646203039976)，使用它做一些基本的事情，沿途拍摄屏幕截图，并在出现问题时报告。如果出于任何原因您想自己运行此测试，可以通过添加 JVM 参数 `-Dwurst.e2eTest` 来实现。

另请参阅：[Wurst 7.46 变更日志](/updates/wurst-7-46/)，[Wurst 7.46.1 变更日志](/updates/wurst-7-46-1/)

## 已知快照问题

-在24w45a-24w46a中，X-Ray无法工作，因为Fabric的Indigo渲染器已被暂时禁用。在1.21.4前1和更高版本中，Indigo仍然被禁用，但X-Ray已被调整为在没有它的情况下工作。

-在1.21.4-rc1-1.21.4-rc3中，如果您使用Fabric API 0.110.5，X-Ray将无法工作。此Fabric API版本带回了Indigo渲染器，由于上述调整，该渲染器现在与X-Ray不兼容。请确保使用推荐的Fabric API 0.110.2，而不是下载最新版本。
